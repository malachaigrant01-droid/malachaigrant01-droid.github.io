Payments

Stripe — not configured Live keys — dashboard only

Engagements are invoiced through Stripe. The button opens a Stripe-hosted payment page; card details go from the payer's browser directly to Stripe and never reach this site or its host.

Payment link not set

This is a static page, so there is no server to hold a Stripe secret key — and a Payment Link needs none. That keeps the secret in the Stripe dashboard, keeps card data off this infrastructure, and keeps this site out of PCI scope. Publishable and secret keys are not required here and must not be committed.
