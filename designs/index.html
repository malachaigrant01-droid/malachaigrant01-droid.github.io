How to read this

Each entry below is rendered in the direction it describes — the ground, the display face, the body colour and the palette strip are the real values, not a swatch approximation. The authorisation marker states where that design can actually be seen, which is not the same question as whether it is finished.

PublicServed on this hub. Readable by anyone with the address, and indexable.
Organisation onlyLives in a Claude Design canvas. Private by default; if shared, the link resolves only for people inside the organisation. Not publicly linkable.

Why authorisation differs

The adopted direction is public because it is the site — it is served to every visitor by definition. The two unadopted directions live in a design canvas, which is private unless deliberately shared, and shareable only inside the organisation because it declares export. That asymmetry is the point: what ships is public, what is still being decided is not.

Nothing on this page is access-controlled. It is a record of how the domain looks and where each direction can be seen — not a gate. Access control for the domain itself is a Cloudflare Zero Trust application on the hostname, described under cloudflare-login-connections.
